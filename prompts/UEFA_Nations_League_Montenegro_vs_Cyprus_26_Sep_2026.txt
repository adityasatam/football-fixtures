# 12. OWN GOAL RULE

If officially recorded as an own goal:

`⚽ OG [MINUTE] [INITIAL. SURNAME] ([GOAL TOTAL])`

Critical rule:

An own goal:

* Counts toward the team's score.
* Does NOT increase the own-goal scorer's individual goal total.
* Must NOT add +1 to the player's individual goal statistic.

Therefore, if the player's pre-match goal total is `[N]` and the own goal is the relevant event:

`⚽ OG [MINUTE] [PLAYER A] ([N])`

unless another legitimate goal event has already changed that player's total.

Never treat an own goal as a normal individual goal.

4. Give greater weight to explicit match-level MOTM/MVP selections than ratings alone.
5. Continue through the deterministic fallback below.

Different secondary ratings, fan votes, editorial selections or provider-specific awards do NOT automatically create a material source conflict.

---

### 6. DETERMINISTIC FALLBACK — GOAL SCORER PRIORITY

If multiple credible MOTM candidates remain after the official-source and secondary-source review:

GOAL SCORER PRIORITY APPLIES.

Among the credible MOTM candidates:

1. If one candidate is a verified goal scorer, select that goal scorer.
2. If multiple credible candidates are verified goal scorers, select the goal scorer supported by the strongest documented secondary-source evidence.
3. If no credible MOTM candidate is a goal scorer, select one credible candidate using the strongest available documented evidence.
4. If all remaining evidence is substantially equivalent, select one credible candidate rather than terminating the workflow.

This fallback is mandatory.

Do not stop merely because several credible secondary sources disagree.

* Visual assumptions
* Image-generation behavior
* Unapproved external information

### MOST IMPORTANT DATA RULE

EVERY NUMBER INSIDE AN EVENT BRACKET MUST BE THE EXACT VERIFIED CURRENT-SEASON, SAME-COMPETITION CUMULATIVE STATISTIC IMMEDIATELY AFTER THAT SPECIFIC EVENT, AS SUPPLIED IN THE APPROVED RENDER DATA LOCK.

### MOST IMPORTANT LAYOUT RULE

EVERY HOME-TEAM EVENT MUST APPEAR ON THE LEFT/HOME SIDE.

EVERY AWAY-TEAM EVENT MUST APPEAR ON THE RIGHT/AWAY SIDE.

THE RENDERER MUST NEVER INFER EVENT-SIDE PLACEMENT FROM CHRONOLOGICAL ORDER.

### MOST IMPORTANT MOTM RULE

THE SYSTEM MUST SELECT EXACTLY ONE MOTM WHEN A CREDIBLE MOTM CANDIDATE EXISTS.

IF MULTIPLE CREDIBLE MOTM CANDIDATES REMAIN AFTER SOURCE REVIEW, A VERIFIED GOAL SCORER AMONG THOSE CANDIDATES TAKES PRIORITY.

IF NO CREDIBLE CANDIDATE IS A GOAL SCORER, SELECT ONE CREDIBLE CANDIDATE USING THE STRONGEST AVAILABLE DOCUMENTED EVIDENCE.

DIFFERING SECONDARY MOTM OPINIONS DO NOT AUTOMATICALLY CONSTITUTE A MATERIAL SOURCE CONFLICT.

NEVER TERMINATE WITH “NO MOTM” MERELY BECAUSE SECONDARY SOURCES DISAGREE.

### MOST IMPORTANT IMMUTABILITY RULE

THE APPROVED RENDER DATA LOCK IS IMMUTABLE.

### MOST IMPORTANT RENDERER RULE

THE IMAGE GENERATOR IS A RENDERER, NOT A FOOTBALL-DATA SOURCE.
